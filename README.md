# 밀크빌리지 재료·재고 관리 MVP

매장 태블릿 가로 화면을 기준으로 만든 정적 웹앱 MVP입니다.

## 실행

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

## Supabase 연결

`supabase-schema.sql` 내용을 Supabase의 SQL Editor에서 한 번 실행하면 여러 기기에서 같은 데이터를 공유합니다.

현재 1차 연결은 `milk_village_state` 테이블의 `main` 행에 앱 상태를 JSON으로 저장하는 방식입니다. 빠르게 태블릿·모바일·노트북 동기화를 확인하기 위한 MVP 구조이며, 이후 운영 안정화 단계에서 정규화된 테이블 구조로 분리할 수 있습니다.

다른 기기의 재고/관리자 변경은 Supabase Realtime으로 즉시 반영하고, 실시간 연결이 지연될 때를 대비해 10초마다 DB를 다시 확인합니다. `supabase-schema.sql`을 다시 실행하면 Realtime publication 설정까지 적용됩니다.

알림도 같은 방식으로 동기화됩니다. 한 기기에서 알림이 울리면 다른 기기에도 모달이 열리고, 확인 완료나 스누즈를 누르면 열린 기기들의 알림 상태도 함께 정리됩니다.

## 관리자 PIN

초기 PIN은 `1234`입니다. PIN 값은 앱 데이터의 `settings.adminPin`에 저장되는 구조라 이후 설정 화면으로 분리하기 쉽습니다.

## 음성 알림

알림은 파일을 업로드하는 방식이 아니라, 관리자가 입력한 한글 문장을 브라우저의 음성 합성 기능으로 읽어주는 방식입니다.

1. 앱을 켠 뒤 상단의 `음성 알림 활성화`를 한 번 누릅니다.
2. 관리자 > 알림 관리에서 `알림 이름`, `알림 시간`, `음성으로 읽을 문구`만 입력합니다.
3. `테스트 실행`으로 실제 음성이 들리는지 확인합니다.

브라우저와 기기에 따라 한국어 음성 합성 품질이 다를 수 있습니다.

소리가 들리지 않으면 태블릿/모바일에서 먼저 상단의 `음성 알림 활성화`를 누른 뒤, 관리자 > 알림 관리의 `테스트 실행`을 눌러 확인합니다. 기기 음량, 무음 모드, 브라우저 음성 합성 지원 여부에 영향을 받을 수 있습니다.

## 수동 검증

1. 재료 만들기에서 `흑당펄 x1 만들기`를 누릅니다.
2. 오늘 제조 로그에 `흑당펄 x1` 한 줄이 생성되는지 확인합니다.
3. 관리자 > 전체 로그 확인에서 냉동타피오카펄, 흑설탕 차감 거래가 생겼는지 확인합니다.
4. 제조 로그의 `취소`를 누르고 확인합니다.
5. 관리자 > 전체 로그 확인에서 취소 복구 거래가 생겼는지 확인합니다.
6. 발주 화면에서 기준량 이하 품목만 표시되는지 확인합니다.
7. 관리자 > 알림 관리에서 알림 시간을 현재 시각 + 1분으로 바꾼 뒤, 알림 팝업과 확인/스누즈 기록을 확인합니다.
8. 관리자 > 알림 관리에서 테스트 실행을 눌러 한글 문장이 읽히는지 확인합니다.

## 저장 방식

현재 MVP는 브라우저 `localStorage`에 데이터를 저장합니다. 데이터 접근 함수와 모델을 `app.js` 안에서 분리해 두어 이후 서버 DB로 옮기기 쉽게 구성했습니다.
